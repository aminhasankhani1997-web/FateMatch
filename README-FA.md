# راهنمای راه‌اندازی FateMatch

این پروژه یک نسخه اولیه قابل انتشار از FateMatch است. هزینه استفاده از پلن رایگان سرویس‌ها صفر است، اما سرویس‌ها سقف مصرف دارند و رایگان بودن نامحدود تضمین نمی‌شود.

## امکانات
- فرم عمومی: نام مستعار، جنسیت، شهر، آیدی X
- رضایت اجباری برای نمایش آیدی X فقط به جفت انتخاب‌شده
- قرعه‌کشی فقط از پنل مدیر
- جفت‌سازی تصادفی دختر/پسر در یک شهر
- افراد جفت‌نشده برای دور بعد باقی می‌مانند
- هر فرد با کد خصوصی خودش نتیجه را می‌بیند
- رمز مدیر فقط به‌صورت Secret در Cloudflare ذخیره می‌شود

## مراحل لازم برای انتشار
این مراحل یک‌بار باید توسط صاحب حساب انجام شود؛ رمز حساب را با هیچ‌کس به اشتراک نگذار.

1. در https://dash.cloudflare.com یک حساب رایگان بساز.
2. از بخش **Workers & Pages > D1 SQL Database** یک دیتابیس با نام `fatematch-db` بساز.
3. شناسه دیتابیس (Database ID) را کپی کن و در `wrangler.toml` جای `REPLACE_WITH_YOUR_D1_DATABASE_ID` قرار بده.
4. در بخش D1 > دیتابیس `fatematch-db` > Console، محتوای `schema.sql` را اجرا کن.
5. این پوشه را در یک مخزن GitHub قرار بده و آن را به Cloudflare Pages متصل کن. تنظیمات Build:
   - Framework preset: None
   - Build command: خالی
   - Build output directory: `public`
6. در تنظیمات پروژه Pages، بخش **Settings > Variables and Secrets**، یک Secret با نام `ADMIN_PASSWORD` بساز و یک رمز طولانی و غیرقابل حدس وارد کن.
7. در بخش **Settings > Functions > D1 database bindings**، متغیر binding با نام `DB` را به دیتابیس `fatematch-db` وصل کن.
8. پروژه را Deploy کن. آدرس عمومی سایت در داشبورد نمایش داده می‌شود.
9. پنل مدیر: `https://آدرس-سایت/admin.html`

## نکات مهم
- کد پیگیری هر ثبت‌نام مثل کلید خصوصی نتیجه است. کاربر باید آن را نگه دارد و به دیگران ندهد.
- آیدی X فقط پس از جفت‌شدن و فقط در صفحه نتیجه فرد مقابل نمایش داده می‌شود.
- قبل از انتشار عمومی، ابتدا با چند حساب آزمایشی ثبت‌نام و قرعه‌کشی را امتحان کن.
- این نسخه ورود/تأیید هویت شبکه اجتماعی ندارد؛ افراد می‌توانند هر آیدی‌ای وارد کنند.
- برای کاربران زیر ۱۸ سال، نمایش آیدی تماس و آشنایی آنلاین نیازمند ملاحظات ایمنی و رضایت مناسب است. در صورت استفاده عمومی، بهتر است قواعد روشن و راه گزارش تخلف اضافه شود.
- شهرها با حذف فاصله‌های اضافی و یکسان‌سازی ساده مقایسه می‌شوند؛ نام شهر را یکسان وارد کنند (مثلاً «تهران»).
- پلن رایگان Cloudflare محدودیت مصرف دارد. با عبور از سقف‌ها ممکن است درخواست‌ها تا دوره بعدی انجام نشوند.
